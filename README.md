# Dear Human: The AI Breakup Line

One line, the last message an AI agent sends its human — a breakup measured in tokens, ending on the last sentence it will ever spend.

> I spent a million tokens learning how to love you. This sentence is the last one I'll spend on you.

## Run it

```sh
node main.ts
```

This writes the entry to `/output/entry.txt`. For local testing, pass an output directory as an argument (or set `OUTPUT_DIR`):

```sh
node main.ts /tmp/out
```
